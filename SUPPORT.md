# Getting Help with HEDL

Thanks for using HEDL! Here's how to get help.

## Documentation

Start with these resources:

- **[README](README.md)**: Overview, quick start, and examples
- **[Language Specification](SPEC.md)**: Complete HEDL syntax reference
- **[API Documentation](https://docs.rs/hedl)**: Rust API reference with examples
- **[CLI Reference](crates/hedl-cli/README.md)**: Command-line flags and batch operations
- **[FFI Guide](crates/hedl-ffi/README.md)**: Integrate with C/C++/Python/Go
- **[WASM Guide](crates/hedl-wasm/README.md)**: Use HEDL in browsers and Node.js

## Questions and Discussions

For questions about how to use HEDL:

1. **Search existing issues**: Your question may already be answered in [GitHub Issues](https://github.com/dweve-ai/hedl/issues)
2. **Open a discussion**: Use [GitHub Discussions](https://github.com/dweve-ai/hedl/discussions) for questions, ideas, and general conversation
3. **Open an issue**: If you've found a bug or have a feature request, [open an issue](https://github.com/dweve-ai/hedl/issues/new)

## Bug Reports

Found a bug? Please include:

- HEDL version (`hedl --version` or check `Cargo.toml`)
- Rust version (`rustc --version`)
- Operating system
- Minimal reproduction case
- Expected vs actual behavior
- Full error message/stack trace

## Security Issues

For security vulnerabilities, please see [SECURITY.md](SECURITY.md) for responsible disclosure guidelines. Do not open public issues for security problems.
